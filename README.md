**화면을 캡처하면 글자와 표를 읽어서, 엑셀·ERP에 붙여넣을 수 있는 형태로 바꿔 주는 Windows 데스크톱 앱**입니다.
API가 없는 프로그램, 복사가 막힌 웹페이지, VDI(가상 PC) 화면처럼 **화면 픽셀로만 읽을 수 있는 곳**에서 일할 때를 위해 만들었습니다.

- 🔒 **100% 로컬 처리** — 화면 이미지는 PC 밖으로 나가지 않습니다 (Windows 내장 한국어 OCR + 선택적 로컬 AI)
- 📜 **긴 화면도 한 번에** — 자동 스크롤하며 캡처해 한 장으로 이어붙입니다
- 📋 **붙여넣기 좋게** — 엑셀에 날짜·0으로 시작하는 숫자가 망가지지 않게 서식과 함께 복사합니다
- 🧠 **틀린 글자는 검증·보정** — 합계 검증, 열 비교, 로컬 AI로 OCR 오류를 줄이고 의심 칸은 색으로 표시합니다

| 기능 | 하는 일 | 자세히 |
|---|---|---|
| **정산 분개** | 이니시스 정산 화면 캡처 → 검증 → 분개 엑셀 양식 → 영림원 붙여넣기 | [정산 문서](docs/settlement.md) |
| **스크롤 캡처** | 영역을 지정하면 자동으로 내려가며 캡처해 한 장으로 합침 (VDI·여러 모니터 지원) | [스크롤 캡처](docs/scroll-capture.md) |
| **DCI 테이블 캡처** | 결제 목록 같은 표 → 엑셀 행/열. 정밀 OCR, 의심 칸 노란색, 로컬 AI 보정 | [DCI 표](docs/dci-table.md) |
| **단축URL 캡처** | 원본URL↔단축URL 추출, 글자 모양·서버 접속 확인으로 `I/l/0/O` 구분 | [단축URL](docs/url-capture.md) |

| **이미지 캡쳐하기** | 캡처한 이미지를 보고 로컬 AI가 프롬프트·설명을 만들어 줌 | [로컬 AI](docs/ai.md) |
| **인쇄** | 스크롤 캡처 이미지를 글자가 잘리지 않게 쪽을 나눠 인쇄 (미리보기 포함) | [인쇄](docs/printing.md) |

## 빠른 시작

**필요한 것**: Windows 10/11 · Python 3.12 · Windows 한국어 언어팩(OCR 포함, *설정 > 시간 및 언어 > 언어*)

```bash
git clone https://github.com/dongdong-com/gtfo-tuegeun-yojeong.git
cd gtfo-tuegeun-yojeong
python -m pip install -r requirements.txt
python app.py          # 또는 run.bat 더블클릭
```

1. **(선택) 환경 설정** — 회사/환경별 값(단축 URL 서버, 상점 ID 등)은 코드에 없습니다. `local_config.example.py`를 `local_config.py`로 복사해 고치세요. 없으면 예시 값으로 동작합니다. → [설정 항목](docs/customization.md#4-회사환경-값--local_configpy)
2. **(선택) 로컬 AI** — AI 보정·프롬프트 기능을 쓰려면 Ollama와 모델이 필요합니다. → [로컬 AI](#로컬-ai-선택)
3. **(정산 화면용) 양식 파일** — 분개 양식 `문서 양식.xlsx`는 저장소에 포함되어 있지 않습니다. 정산 화면을 쓰려면 직접 준비해 같은 폴더에 두세요.

> 💡 코드를 고친 뒤에는 **앱을 껐다 켜야** 반영됩니다. (파이썬은 시작할 때 코드를 읽습니다)

## 화면 구성

```
정산
 └ 포스티니
    ├ 선급금/미지급금 처리      PG 결제대금 입금 + 수수료 선급/미지급 분개
    └ PG(이니시스) 수수료 정산   세금계산서 + 통합정산내역 → 상점별 수수료 전표
운영
 ├ Data&Url캡쳐
 │  ├ 단축URL 캡처             원본URL↔단축URL, I/l 접속 확인
 │  └ DCI 테이블 캡처           일반 표 → 엑셀 행/열 (+ AI 보정)
 └ AI캡쳐하기
    ├ 텍스트 캡쳐하기           복사 불가 화면의 글자 → 텍스트 (+ AI 보정)
    └ 이미지 캡쳐하기           이미지 → 프롬프트 만들기 (로컬 AI)
```

메뉴는 `app.py`의 `MENU`로 바꿀 수 있습니다 → [커스터마이징](docs/customization.md)

## 기능 둘러보기

### 어디서나 같은 흐름

**가져오기 → 읽기 → 확인·수정 → 내보내기** 순서이고, 캡처 화면들은 같은 도구를 씁니다.

| 단계 | 방법 |
|---|---|
| 가져오기 | 화면 영역 캡처 · 영역 지정 + 자동 스크롤 캡처 · 이미지 파일 열기 · 클립보드 이미지 붙여넣기 |
| 읽기 | Windows 내장 OCR (배율·선명화·정밀 OCR 조절) |
| 확인·수정 | 텍스트 상자에서 직접 수정, 의심 칸은 색 표시, `OCR 다시`로 재인식 |
| 내보내기 | 표 데이터 복사(엑셀 서식 포함) · 엑셀로 저장 · 이미지 복사 · PNG 저장 · **인쇄** |

### 정산 (분개)

이니시스 화면에서 **헤더 + 데이터 행만 좁게** 드래그하면 읽고, 합계 검증식으로 OCR 오류를 확인합니다. 어긋나면 배율을 바꿔 다시 읽고, 후보가 정확히 하나일 때만 자동 보정하며 알려 줍니다. 결과는 **행번호~활동센터 8열**만 클립보드에 복사되어 영림원 그리드에 `Ctrl+V` 합니다. → [정산 문서](docs/settlement.md)

### 스크롤 캡처

영역을 지정하면 맨 위로 이동 → 캡처 → 스크롤을 반복하다가 끝에서 멈추고, 프레임 사이 겹침을 찾아 한 장으로 합칩니다. 고정 헤더·푸터는 자동으로 제외하고, 스크롤이 안 먹으면 **큰 휠 → PageDown → ↓ → Space** 순서로 자동 전환합니다. 캡처 중에는 마우스 옆에 안내 말풍선이 뜨고(캡처 이미지에는 찍히지 않음), `ESC`로 중단합니다. → [스크롤 캡처](docs/scroll-capture.md)

### DCI 테이블

표를 행/열로 나눠 엑셀에 바로 붙입니다. 셀 안에서 여러 줄로 줄바꿈되는 표, 썸네일이 섞인 표, 날짜·고유번호·반복값 보정, **의심 칸은 엑셀에서 연노랑**으로 표시합니다. 로컬 AI가 칸 그림을 한 칸씩 읽어 틀린 글자를 고치고, 줄바꿈 때문에 갈라진 띄어쓰기(`자 기소개서`)도 고칩니다. → [DCI 표](docs/dci-table.md)

### 단축URL

단축 URL 관리 화면에서 원본URL↔단축URL을 뽑습니다. 화면에서 똑같이 생긴 `I`/`l`, `0`/`O`/`o`는 **글자 모양**과 **단축 URL 서버 접속 확인**(ID만 전송)으로 가려내고, 확정하지 못한 글자는 `?`나 확인필요 열로 알려 조용히 틀린 URL이 나가지 않게 합니다. → [단축URL](docs/url-capture.md)

### 텍스트·이미지 캡쳐

복사·선택이 막힌 웹페이지, 이미지 속 글자를 텍스트로 뽑습니다. 줄 그대로 / 문단으로 합치기 / 한 줄로, 다단 읽기, 어두운 배경 자동 반전, 영문 0/1 보정을 지원합니다. → [텍스트](docs/text-capture.md)

### 인쇄

스크롤 캡처한 긴 이미지를 **글자가 없는 줄에서 쪽을 나눠** 인쇄합니다. 용지 방향 자동, 쪽번호·날짜 바닥글, Windows 인쇄 미리보기와 프린터 선택을 지원합니다. → [인쇄](docs/printing.md)

## 로컬 AI (선택)

AI 기능은 **내 PC에서만 도는 [Ollama](https://ollama.com) + Gemma 4 E2B**를 씁니다. 이미지와 결과는 밖으로 나가지 않으며, 설치하지 않아도 나머지 기능은 모두 동작합니다.

```bash
winget install Ollama.Ollama
ollama pull gemma4:e2b        # 약 4.6GB
```

- **모델 파일은 이 저장소에 들어 있지 않습니다.** Ollama가 내려받아 사용자 폴더(`.ollama\models`)에 저장합니다. 저장소에는 모델을 호출하는 코드(`aillm.py`)만 있습니다.
- Ollama가 꺼져 있으면 AI 버튼을 누를 때 퇴근요정이 알아서 켭니다.
- GPU 없는 노트북 CPU에서 10~60초 정도 걸립니다.
- AI는 **틀릴 수 있어서** 바뀐 칸을 색으로 표시하고 `AI 보정 되돌리기`를 둡니다. 단축 URL ID·정산 금액처럼 AI가 값을 지어내면 위험한 곳에는 쓰지 않습니다.

| 어디서 | 무엇을 | 자세히 |
|---|---|---|
| DCI 테이블 | 칸 그림 읽기 보정, 띄어쓰기 보정 | [DCI 표](docs/dci-table.md#ai로-보정-로컬-ai) |
| 텍스트 캡쳐하기 | OCR 결과를 이미지와 비교해 보정 | [텍스트](docs/text-capture.md) |
| 이미지 캡쳐하기 | 이미지 → 이미지 생성용/UI 구현용 프롬프트, 설명, 직접 지시 | [로컬 AI](docs/ai.md) |

## 커스터마이징

메뉴·화면·AI·색은 파일 한두 군데만 고쳐서 바꿀 수 있습니다.

```python
# app.py — 메뉴 한 줄 추가 / 삭제 / 이동
MENU = [("내 도구", [("안녕", HelloPage)])] + MENU
```

| 하고 싶은 일 | 어디를 고치나 |
|---|---|
| 메뉴 이름·순서·숨기기 | `app.py`의 `MENU` |
| 새 화면 추가 | `ttk.Frame`을 상속한 클래스를 만들어 `MENU`에 등록 |
| 기존 캡처 화면 변형 | `DciTablePage` 등을 상속해 `TITLE`·`DEFAULT_SCALE`·훅 덮어쓰기 |
| 회사/환경 값 | `local_config.py` (git에 올라가지 않음) |
| AI 모델·프롬프트 종류 | `aillm.py`의 `MODEL`, `IMAGE_PROMPTS` |
| 색·캐릭터·창 제목 | `theme.py`, `assets/`, `app.py` |

예제 코드와 전체 목록 → **[커스터마이징 문서](docs/customization.md)**

## 알려진 한계

- **세금계산서 캡처**는 양식에 포함된 이미지로만 검증했습니다. 실제 화면에서 확인이 필요합니다.
- 무이자수수료는 현재 수수료에 합산합니다. 정산 행이 월 2건(1~15일, 16일~말일)을 넘는 경우는 고려하지 않았습니다.
- 한글이 아주 작으면(약 12px 이하) OCR이 틀릴 수 있습니다. 중요한 값은 원본과 대조하세요.
- 화면 밖으로 잘린 열(가로 스크롤이 필요한 열)은 읽을 수 없습니다.
- 대문자 `I`와 소문자 `l`은 화면에서 모양이 같아 서버 접속 확인 없이는 확정할 수 없습니다.
- 인쇄는 미리보기까지 확인했고, 실제 프린터 출력은 환경에 따라 한 번 확인이 필요합니다.
