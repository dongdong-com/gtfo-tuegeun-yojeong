# 정산 화면 (정산 > 포스티니)

[← README로 돌아가기](../README.md) · [문서 목록](../README.md#문서)

이니시스(KG) 정산 화면을 캡처해서 분개 엑셀 양식으로 만들고, 영림원에 붙여넣는 두 화면입니다.

## 사용 방법

1. 이니시스에서 해당 화면을 조회합니다.
2. **화면 영역 캡처**를 누르고, 표의 **헤더 + 데이터 행만 좁게** 드래그합니다. (합계 행 제외, 화면 전체를 잡으면 인식률이 떨어집니다)
3. 읽힌 값과 검증 표시(✔ 일치 / ⚠ 차이)를 확인하고 필요하면 수정합니다.
4. **클립보드 복사** 후 영림원 그리드에서 `Ctrl+V` 하거나, **엑셀로 저장**합니다.

## 선급금/미지급금 처리

- 구분: `매월 8일 미지급금` / `매월 22일 선급금`
- 캡처 대상: **통합정산내역조회**
- 상점ID × 정산기간마다 3줄 생성: 예치금-pg(차) / 미수금-PG(카드)(대) / 미지급금-PG 또는 선급금-PG(차, 수수료+부가세)

## PG(이니시스) 수수료 정산

- 대상 상점: 설정(`local_config.py`의 `STORE_IDS`)에 적은 상점들
- 캡처 대상: **세금계산서 발행내역조회**(공급가액·세액), **통합정산내역조회**(정산일 1~15일 / 16일~말일)
- 상점당 4줄 생성: 지급수수료-PG수수료(판관) / 부가세대급금 / 선급금-PG(대) / 미지급금-PG(대)
- 선택 입력: 계좌성명조회 등 기타 수수료 (미지급금-거래처)

## 검증과 자동 보정

OCR 오인식을 막기 위해 합계 검증식을 사용합니다.

| 화면 | 검증식 |
|------|--------|
| 통합정산내역 | 거래금액 = 지급액 + 수수료 + 부가세 |
| 세금계산서 | 공급가액 + 세액 = 합계 |
| 수수료 정산 | 세금계산서 (공급가액+세액) = 통합정산내역 한 달 (수수료+부가세) |

- 검증이 어긋나면 배율·선명화를 바꿔 OCR을 다시 시도합니다.
- 그래도 어긋나면 한 자리 혼동(5↔6, 3↔8 등) 수정으로 맞는 후보가 **정확히 1개일 때만** 자동 보정하고, 팝업으로 알립니다. 보정 알림이 뜨면 반드시 이니시스 화면과 대조하세요.
- 후보가 없거나 여러 개면 값을 바꾸지 않고 경고만 표시합니다.

## 영림원 붙여넣기 주의

- 클립보드에는 **행번호~활동센터(8열)** 만 복사됩니다. 관계회사·관리항목까지 붙여넣으면 `Invalid column index` 오류가 납니다. 관리항목은 영림원에서 직접 입력/코드도움으로 선택하세요.
- 수수료 정산 탭은 차변/대변의 빈 쪽을 `0`으로 채웁니다 (양식과 동일).
