# 로컬 AI 기능 (Gemma 4 E2B)

[← README로 돌아가기](../README.md) · [문서 목록](../README.md#문서)

이 PC에서만 도는 **Ollama + Gemma 4 E2B**(Apache 2.0, 약 4.6GB)를 씁니다. 이미지·결과는 밖으로 나가지 않습니다. 이 PC(i7-1360P, GPU 없음, RAM 31.6GB)에서는 CPU로 돌리며 **10~60초** 걸립니다.

## 설치

- 설치: `winget install Ollama.Ollama` → `ollama pull gemma4:e2b` (이미 설치됨). 퇴근요정이 꺼져 있는 Ollama 서버를 알아서 켭니다(`aillm.py`). 없으면 버튼을 눌렀을 때 설치 안내가 나옵니다.

## 시험 결과와 쓰는 방식

- 시험 결과(카드 4장 합성 이미지): Windows OCR만 → 로고(ENF, KTR, BORYUNG)·작은 글자·날짜 누락/오인식 / **Windows OCR 초안 + AI 보정 → `한국알콜산업 계열사`, `한국화학융합시험연구원`, `D-3`까지 복구 (14초)**. 반면 AI가 이미지만 보고 직접 읽으면 `하반기→한방기`처럼 지어내는 글자가 있어, **OCR 초안을 함께 주는 방식**을 씁니다. 일반 문단에서도 `바꿔 줍니다`→`바꿉니다`처럼 말투를 바꾸는 일이 있어 **바뀐 줄을 노란색으로 보여 주고 되돌리기**를 둡니다.

- 쓰지 않는 곳: 단축 URL ID, 정산 금액(AI가 그럴듯한 값을 만들 수 있음 — 서버 접속 확인·합계 검증 유지).

## 화면별

- **텍스트 캡쳐하기** — `AI로 보정` 버튼 — 현재 텍스트와 이미지를 AI에게 보여 주고 틀린 글자·빠진 글자를 고칩니다(바뀐 줄 노란색, `AI 보정 되돌리기`로 원문 복구, 실행 중 같은 버튼이 `AI 중단`). 아래 설명의 기본 OCR 기능은 그대로입니다.
- **이미지 캡쳐하기** — 가져오기(영역·스크롤 캡처, 파일, 클립보드)는 텍스트 캡쳐하기와 같고, `프롬프트 만들기`가 이미지를 보고 프롬프트를 씁니다. 만들 것: `이미지 생성 AI용 프롬프트` / `화면(UI) 구현용 프롬프트` / `이미지 설명(대체 텍스트)` / `직접 지시`(예: "이 표를 마크다운으로 바꿔줘"). 답 언어는 한국어/English. `이미지 속 글자(OCR)도 참고로 전달`(기본 켬)은 AI가 작은 글자를 지어내는 것을 줄입니다(+약 4초). 결과는 수정·복사·.txt 저장 가능.
- **DCI 테이블 캡처** — [DCI 문서](dci-table.md#ai로-보정-로컬-ai) 참고

## 재부팅 후

모델 파일은 디스크(사용자 폴더의 `.ollama\models`, 약 4.3GB)에 있어 재부팅해도 다시 받을 필요가 없습니다. Ollama는 로그인할 때 자동으로 시작되고, 꺼져 있어도 퇴근요정이 버튼을 누를 때 서버를 켭니다. 재부팅 직후 첫 사용은 모델을 메모리에 올리느라 몇 초 더 걸릴 수 있습니다.
