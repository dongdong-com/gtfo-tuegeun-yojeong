# 텍스트 캡쳐하기 (운영 > AI캡쳐하기)

[← README로 돌아가기](../README.md) · [문서 목록](../README.md#문서)

이미지 속 글자, 또는 **텍스트 선택·복사가 안 되는 웹페이지/VDI 화면**의 글자를 화면 픽셀에서 읽어 텍스트로 뽑습니다. 모든 처리는 이 PC에서만 합니다(Windows 내장 OCR).

**① 가져오기** — 네 가지 중 하나를 고릅니다.
- **화면 영역 캡처 (스크롤 없음)**: 드래그한 영역만 한 장 캡처
- **영역 지정 + 자동 스크롤 캡처**: 긴 페이지를 위에서 아래로 스크롤하며 한 장으로 이어붙임 (단축URL/DCI와 같은 기능: 창 활성화·자동 전환·끝에서 아래쪽 보충·안내 말풍선)
- **이미지 파일 열기…**: png·jpg·webp·bmp·gif·tif (휴대폰 사진의 회전 정보 반영)
- **클립보드 이미지 붙여넣기**: `Win+Shift+S` 캡처나 복사한 이미지, 탐색기에서 복사한 이미지 파일

**② 추출된 텍스트** — 읽은 뒤 설정만 바꾸면 **재인식 없이** 바로 다시 정리됩니다.
| 옵션 | 설명 |
|------|------|
| 줄바꿈 | `줄 그대로` / `문단으로 합치기`(줄 간격이 1.35배 넘게 벌어지거나 짧게 끝나는 줄 뒤에서 문단을 나누고, 같은 문단의 줄은 공백으로 이음. 영어 하이픈 줄바꿈도 합침) / `한 줄로` |
| 다단(2단 이상) 읽기 | 세로로 넓게 비어 있는 구간으로 열을 나눠 **열마다 위→아래**로 읽음 (끄면 두 열의 같은 높이 글자가 한 줄로 섞임. 합성 2단 이미지에서 읽는 순서 일치율 45% → 99.6%) |
| 공백 정리 | 연속 공백을 하나로 (끄면 벌어진 칸이 공백 3칸으로 남음) |
| 영문 단어 속 0/1 보정 | 소문자 단어 안에서 `t00`→`too`, `w0rld`→`world`, `hel1o`→`hello`. `H2O`, `mp3`, `ver10`, `2026-11-05`처럼 숫자가 섞인 정상 값은 건드리지 않음 |
| 어두운 배경 자동 반전 | 이미지 중앙값 밝기가 낮으면(다크 모드 등) 반전해서 읽음 |
| OCR 언어 / 배율 / 선명화 | 언어는 설치된 OCR 언어가 자동으로 나열됩니다(이 PC는 한국어뿐이며 영어 글자도 함께 읽음). 다른 언어는 Windows 설정 > 시간 및 언어 > 언어에서 해당 언어(OCR 포함)를 설치하세요. 배율 기본 3.0 |
| OCR 직후 자동 복사 | 읽자마자 클립보드에 넣음 (기본 켜짐) |

**출력**: `텍스트 복사`, `텍스트 파일(.txt)로 저장`(BOM·CRLF라서 메모장/엑셀에서 한글이 안 깨짐), `이미지에서 영역만 다시 읽기…`(이미지에서 원하는 부분만 드래그해 그 부분만 읽음), 이미지 복사·PNG 저장.

정확도(합성 한글 문단 이미지, 맑은 고딕): 13·15·18px에서 글자 일치율 96~98.6%, 배율 3.0이 가장 안정적입니다. 글자가 작거나 흐리면 배율을 올리세요. 한국어 OCR은 영문 `o`/`l`을 숫자로, 한글 일부(`처리`→`저리`)를 틀리게 읽는 일이 있으니 중요한 글은 원본과 대조하세요.

## AI로 보정

`AI로 보정` 버튼 — 현재 텍스트와 이미지를 AI에게 보여 주고 틀린 글자·빠진 글자를 고칩니다(바뀐 줄 노란색, `AI 보정 되돌리기`로 원문 복구, 실행 중 같은 버튼이 `AI 중단`). 아래 설명의 기본 OCR 기능은 그대로입니다.
